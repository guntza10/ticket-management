# เลือกโมเดล Claude ให้เหมาะกับงาน

## Claude มีหลาย tier

เรียงจากถูก/เร็ว → ฉลาด/แพง:

| โมเดล | ราคา (ต่อ 1M tokens, in/out) | เหมาะกับ |
|---|---|---|
| **Haiku 4.5** | $1 / $5 | งานง่าย เร็ว ปริมาณเยอะ |
| **Sonnet 4.6** | $3 / $15 | สมดุล เร็ว+ฉลาด |
| **Opus 4.8** | $5 / $25 | งานยาก ต้องฉลาดสุด |
| **Fable 5** | $10 / $50 | สุดยอด (งานหนักมากๆ) |

> in = token ที่ส่งเข้า (prompt), out = token ที่ได้ออกมา (คำตอบ)

---

## หลักการเลือก

> **"งานนี้ต้อง*ฉลาด*แค่ไหน vs ต้อง*เร็ว/ถูก*แค่ไหน?"**

**ไม่จำเป็นต้องใช้โมเดลเดียวกันทุกงาน** — เลือกต่องานได้:

| งานในโปรเจกต์เรา | โมเดล | เพราะ |
|---|---|---|
| จัดประเภท ticket | Haiku | ง่าย ปริมาณเยอะ → เน้นถูก+เร็ว |
| สรุปปัญหา | Haiku / Sonnet | ไม่ต้องฉลาดมาก |
| ร่างคำตอบให้เป็นธรรมชาติ | Sonnet / Opus | หัวใจ — คุณภาพ/น้ำเสียงสำคัญสุด |

## เคล็ดลับสำหรับ MVP

**ใช้ `claude-opus-4-8` ตัวเดียวทุกงานไปก่อน** (คุณภาพดีสุด ไม่ต้องคิดเยอะ)
แล้วค่อย optimize งานง่ายๆ ไปใช้ Haiku ทีหลังเพื่อลดค่าใช้จ่าย
→ ตรงกับหลัก "MVP ก่อน แล้วค่อยปรับ"
